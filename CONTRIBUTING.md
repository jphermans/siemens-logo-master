# Contributing

- Preserve top-level `SKILL.md` and valid YAML frontmatter with `name` and `description`.
- Keep all Siemens block names, pins and parameters grounded in the correct official version.
- Label unverified diagrams and avoid claims of simulation without actual execution.
- Run `python scripts/validate_skill.py` and PDF-rendering tests before committing.
- Distribute ZIP with `SKILL.md` at archive root (no enclosing folder).
- Version changes clearly. Submit improvements through pull requests.
