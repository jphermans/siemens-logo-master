# Documentation and research protocol

Use Siemens as the primary authority. Identify the exact version and hardware before making block-level assertions.

Starting points (URLs must be rechecked when working online):
- Siemens Industry Online Support / SiePortal: https://support.industry.siemens.com/
- Siemens LOGO! documentation and downloads via SiePortal search: https://sieportal.siemens.com/
- LOGO! Soft Comfort V8.3.1 online help PDF (verify revision): https://cache.industry.siemens.com/dl/files/807/109974807/att_1299328/v4/Help_en-US_en-US.pdf
- LOGO! system manual (verify hardware edition): https://cache.industry.siemens.com/dl/files/732/109974732/att_1341396/v1/logo_system_manual_en-US_en-US.pdf

Procedure:
1. Find applicable manual, version, publication date and official link.
2. Search exact block label, FBD editor category, terminals and supported hardware.
3. Look up one or more relevant application examples online. Prefer Siemens; third-party examples are secondary.
4. Compare example against official documentation, identify differences.
5. Cite manual title, section/page when known, URL and date accessed. If browsing is unavailable, mark `documentation not checked live` and request a manual/upload for uncertain details.
6. Do not reproduce large copyrighted manual passages or vendor graphics. Create original technical illustrations.
