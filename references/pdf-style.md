# PDF design specification

A4 landscape, white paper, light technical grid optional, dark neutral text, fine blue-gray lines, cyan/blue title accents. Inspired by an engineering printout from LOGO! Soft Comfort, **not a branded or authentic export**.

Pages:
1. Cover/functional overview and requirements, technical title block.
2. Full readable FBD drawing, left-to-right with inputs on left, block IDs/names, exact terminals, outputs on right, connector lines and a legend. If too complex, split into numbered diagram sheets and mark cross-sheet references.
3. Input/output allocation and block/parameter tables.
4. Step-by-step placement and exact pin-to-pin wiring instructions.
5. Test matrix, safety notes, sources and revision history.

Each sheet: project, version, LOGO! hardware, software version, page x/y, verification status and date dd-mm-yyyy. Never sacrifice legibility to fit one page. Native screenshots only if user supplied or legally available and correctly attributed.

Do not use Siemens logos or claim Siemens certification. Do not mislabel an illustrative schematic as a validated native FBD export.
